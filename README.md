## Anton Dergunov

I'm a machine learning engineer and applied scientist based in London.

My work sits where machine learning meets real user behaviour: I build production systems that learn from how millions of people search, click, and choose — and that have to prove, in live experiments, that they actually got better. Most of that work has been in search ranking, recommendations, and NLP at large scale, from classical learning-to-rank through transformer-based models and LLM-powered pipelines.

At Microsoft, I spent over seven years as a Senior Applied Scientist working on ranking and recommendation systems across Microsoft 365. Before Microsoft, I worked on video search at Yandex, and earlier spent a decade at Intel on performance-analysis tools for parallel software. I hold a PhD in Computer Science.

These are my own projects: research and ML first, then the tools I built and use. Anything marked _prototype_ or _planned_ is in progress.

## Research and ML

### Evaluation and post-training

- **[llm-agent-eval-testbed](https://github.com/anton-dergunov/llm-agent-eval-testbed)**: Test bed for evaluating LLM agents: a support agent whose decisions are made by deterministic code, scored by checks, adversarial guardrails and a calibrated LLM judge.
- **[mandarin-speech-coach](https://github.com/anton-dergunov/mandarin-speech-coach)**: Mandarin pronunciation practice that shows the evidence instead of a score: your pitch contour against a target phrase, aligned per character (Whisper, wav2vec2 CTC alignment, F0 tracking). _(prototype)_

### Retrieval and ranking

- **[spoken-usage-retrieval](https://github.com/anton-dergunov/spoken-usage-retrieval)**: Retrieving and ranking authentic word and phrase usage from native speech.
- **[task-concept-retrieval](https://github.com/anton-dergunov/task-concept-retrieval)**: Given a short task description, retrieve the most appropriate concept from a fixed vocabulary of 4,257 visual symbols: hybrid lexical-semantic retrieval, embedding models, reranking, calibration, and abstention.

### Agents and context engineering

_Preparing content so that an LLM agent can use it: extraction to clean Markdown, retrieval done ahead of the agent, and the token cost measured._

- **[agentic-org-planner](https://github.com/anton-dergunov/agentic-org-planner)**: Org-mode planning system for Emacs with an LLM agent working on the plan: it adds, files and edits tasks in your own files, every change reviewed as a diff.
- **[agent-context-pipeline](https://github.com/anton-dergunov/agent-context-pipeline)**: Capture from any device, extraction to clean Markdown (web pages, PDFs, OCR, speech), and retrieval of related notes, delivered as an inbox a coding agent can file.
- **[agentic-paper-library](https://github.com/anton-dergunov/agentic-paper-library)**: Reading and organising a research-paper library with a coding agent: papers converted to Markdown the agent can read and cite, and skills for adding, reading and reviewing them.

### Applied LLM and speech systems

- **[acervo-llm-dictionary](https://github.com/anton-dergunov/acervo-llm-dictionary)**: Personal dictionary whose content is generated by LLMs and multimodal models and approved by the learner: entries, pictures, voices, clips of native speech, audio loops and illustrated stories, tuned by experiment.
- **[lexibeat](https://github.com/anton-dergunov/lexibeat)**: Language-learning audio loops: your words spoken on a beat grid over procedural music, reproducible from a seed.

### Implemented from scratch

- **[foundation-models-experiments](https://github.com/anton-dergunov/foundation-models-experiments)**: Modern ML implemented from scratch in PyTorch: neural retrieval, transformers and ViT, image captioning, audio models and efficient fine-tuning, RLHF and preference optimisation.
- **[hugging-face-deep-rl](https://github.com/anton-dergunov/hugging-face-deep-rl)**: Deep reinforcement learning notebooks with a shared library: a cleaned-up, modernised take on the hands-on units of the Hugging Face Deep RL course.
- **distributed-ml-training**: Multi-GPU and distributed training with PyTorch. _(private for now)_

## Tools I built and use

- **[vscode-pdf-viewer](https://github.com/anton-dergunov/vscode-pdf-viewer)**: Minimal PDF viewer for VS Code with highlights and links to a section or page, including from the Claude Code chat.
- **[lightroom-bracket-stacker](https://github.com/anton-dergunov/lightroom-bracket-stacker)**: Plugin for Adobe Lightroom Classic that finds exposure-bracketed sequences and imports each one as a stack, ready for HDR merge.
- **[vim-mastery](https://github.com/anton-dergunov/vim-mastery)**: A mobile-first, offline-capable course for learning Vim through short exercises, with every taught command checked against native Vim.
- **[harmonic](https://github.com/anton-dergunov/harmonic)**: A minimal distraction-free Spotify playback controller for macOS. Control your music from the menu bar — skip tracks, toggle likes, and view track info at a glance.
- **[calorie-logger](https://github.com/anton-dergunov/calorie-logger)**: A small, private calorie and macro logger you host yourself: few taps to log, and the day shown as a table.
- **[workspace-backup](https://github.com/anton-dergunov/workspace-backup)**: Lightweight source-oriented backup system for research, ML, and software engineering workspaces built on top of restic, resticprofile, rclone and apprise.
- **[freshrss-math-render](https://github.com/anton-dergunov/freshrss-math-render)**: FreshRSS extension that recovers TeX left in feed placeholders and converts it to native MathML before reader apps receive the article.
- **[mic-guard](https://github.com/anton-dergunov/mic-guard)**: macOS menu-bar utility that stops chosen microphones, such as Bluetooth headphones, from becoming the default audio input.
